# Álcool ou gasolina?

Este projeto é uma calculadora simples que ajuda a comparar os preços do álcool e da gasolina. Informe o preço de cada combustível e clique em **Calcular**. O programa compara o preço do álcool com o da gasolina: se a proporção for igual ou maior que 0,7, recomenda gasolina; caso contrário, recomenda álcool.

## Sobre o projeto

O código foi escrito manualmente como um exercício de aprendizado, usando HTML para a página e JavaScript para fazer o cálculo e mostrar o resultado. O Bootstrap é usado para a formatação visual da página.

## Como usar

Abra o arquivo `index.html` em um navegador, digite os preços do álcool e da gasolina e clique em **Calcular**.
